## Entry rules

- Capture start and end from the local clock where practical. If either is
  unknown, write `unknown` rather than inventing it.
- Count active work only. Mark long waits or breaks separately.
- Describe commands/tests that actually ran and record failures as failures.
- Keep synthetic unit-test time/results separate from live recognition runs.
- A live run entry must state the exact configured model, attempts/retries,
  reported usage, browser/server/AI durations when measured, and result.
- Use `not measured` or `unknown` when instrumentation or pricing data is
  unavailable.
- Do not log the user's offline preparation, photography, video recording, or
  deployment time unless the user supplies an actual measurement and asks for
  it to be recorded.
